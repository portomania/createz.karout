# CREATEZ

Geschäftsführer-Cockpit der CREATEZ GmbH – mobile Portal-App (PWA) mit
Einsatz-Kalender, Aufgaben, Finanzen und Notizen. Offline nutzbar und
installierbar auf dem Smartphone.

- `app.html` – die App (Login-PIN, Kalender, Aufgaben, Finanzen, Notizen)
- `index.html` – Startseite mit Button „Cockpit öffnen"

## Admin-Zugang (PIN)

- Erst-PIN: **1234** – gilt **pro Gerät/Browser** (die PIN wird lokal auf dem
  Gerät gespeichert, nicht auf einem Server). Auf einem neuen Gerät gilt also
  wieder die Erst-PIN.
- PIN ändern: in der App unter „Mehr" → „PIN ändern".
- PIN vergessen: auf dem Login-Bildschirm „PIN vergessen?" antippen – die PIN
  wird zurückgesetzt und direkt eine neue festgelegt. Alle Daten (Termine,
  Aufgaben, Finanzen, Kunden, Rechnungen …) bleiben dabei erhalten.
